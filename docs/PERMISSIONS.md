# LiftCore — الصلاحيات والأدوار

## الأدوار

| الدور | الكود | الوصف |
|-------|-------|--------|
| مدير النظام | `admin` | كامل — إعدادات، مستخدمون، حذف |
| مدير عمليات | `manager` | تشغيل يومي — بدون إعدادات حساسة |
| عرض فقط | `viewer` | قراءة — بدون تعديل (ما عدا حسابه) |
| **مخصص** | `custom` | **تختار الصلاحيات** من قائمة عند إنشاء المستخدم |

الفنيون: `/field/login` — منفصل عن أدوار المكتب.

## الدور «مخصص»

1. **الإعدادات** → **المستخدمون** → إضافة أو تعديل
2. اختر الدور: **مخصص**
3. تظهر قائمة الصلاحيات — حدّد ما يحتاجه الموظف (عرض / تعديل لكل قسم)
4. احفظ

مثال: محاسب = مالية + تقارير فقط. مشرف فني = صيانة + أعطال + فنيين.

> الحذف وإعدادات النظام **للـ admin فقط** — غير متاحة في الدور المخصص.
