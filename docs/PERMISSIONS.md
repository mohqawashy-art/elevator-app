# LiftCore — الصلاحيات والأدوار

## الأدوار الأساسية (دائماً)

| الدور | الوصف |
|-------|--------|
| **مدير النظام** `admin` | كامل — إعدادات، مستخدمون، حذف |
| **مدير عمليات** `manager` | تشغيل يومي — بدون إعدادات حساسة أو حذف |
| **عرض فقط** `viewer` | قراءة — بدون تعديل (ما عدا حسابه الشخصي) |

الفنيون: جلسة منفصلة `/field/login` — ليست جزءاً من أدوار المكتب.

## الصلاحيات الاختيارية (جديد)

**افتراضياً: معطّلة** — السلوك كما كان (أدوار فقط).

### التفعيل

1. **الإعدادات** → **المستخدمون**
2. فعّل **«تفعيل الصلاحيات الاختيارية»**

أو على السيرفر: `LIFTCORE_CUSTOM_PERMISSIONS=1` في `platform.env`

### لكل مستخدم

عند الإضافة أو التعديل:

- **منح** — صلاحية إضافية فوق الدور
- **حجب** — إزالة صلاحية كان الدور يعطيها

مثال: مستخدم **عرض فقط** + منح **تعديل العملاء** → يقدر يضيف عملاء بدون ما يكون manager.

مثال: **مدير عمليات** + حجب **عرض المالية** → ما يشوف الفواتير ولا قائمة المالية.

> **مدير النظام** يبقى بصلاحيات كاملة دائماً — لا يُخصَّص له حجب.

### قائمة الصلاحيات

| المجموعة | قراءة | كتابة |
|----------|-------|-------|
| عام | لوحة التحكم | — |
| العملاء | عملاء، عقود | تعديل |
| المصاعد | عرض | تعديل |
| الفريق | فنيون | تعديل |
| العمليات | صيانة، أعطال | تعديل |
| التركيب | تقديرات، مشاريع | تعديل |
| المالية | إيرادات، فواتير | تعديل |
| المخزن | أصناف، حركة | تعديل |
| التقارير | كل التقارير | — |
| الإدارة | — | إعدادات، حذف، إصلاح فوترة |
