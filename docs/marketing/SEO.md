# ظهور LiftCore في بحث Google (SEO)

لا يوجد زر يجعل الموقع «الأول» فوراً. Google يرتّب حسب الصلة والثقة والروابط عبر أسابيع/أشهر.

## كلماتك — ماذا نتوقع؟

| الكلمة | الواقع |
|--------|--------|
| برنامج إدارة المصاعد | هدف رئيسي — صفحة مخصّصة |
| إدارة مصاعد | هدف متوسط — يظهر مع الوقت |
| برنامج مصاعد | هدف متوسط |
| برنامج صيانة المصاعد | هدف قوي |
| مصاعد وحدها | عامة جداً (شركات تركيب/صيانة/قطع) — صعب جداً بدون إعلان أو أشهر طويلة |

**للظهور الفوري على هذه الكلمات:** إعلان Google Ads على `/start`.

**للبحث المجاني:** محتوى + فهرسة + روابط محلية (مكة).

## ما تم تجهيزه

- `robots.txt` + `sitemap.xml`
- عناوين ووصف بكلمات الإدارة/البرنامج
- صفحة محتوى: `https://liftcoreapp.com/برنامج-ادارة-المصاعد`
- بديل إنجليزي لنفس الصفحة: `/elevator-management`
- بيانات منظمة + أسئلة شائعة (FAQ)

## خطواتك في Search Console (مهم)

1. أرسل مجدداً: `https://liftcoreapp.com/sitemap.xml`
2. افحص URL: `https://liftcoreapp.com/برنامج-ادارة-المصاعد` → **طلب فهرسة**
3. افحص أيضاً الصفحة الرئيسية و`/pricing`
4. بعد أيام: راقب تقرير «الأداء» للكلمات التي تظهر فعلياً

## ما يرفع الترتيب فعلياً

- Google Business Profile باسم النشاط في مكة (إن أمكن)
- منشور LinkedIn/شركاء يربط لصفحة برنامج إدارة المصاعد
- مقال إضافي كل أسبوعين عن مشكلة تشغيل حقيقية (عقود، زيارات، أعطال)
- الإعلان أثناء بناء الظهور العضوي

## توقع زمني

- الفهرسة: أيام إلى أسبوعين
- ظهور على كلمات طويلة (برنامج إدارة صيانة المصاعد…): أسابيع
- كلمات قصيرة جداً مثل «مصاعد»: شهور أو إعلان مدفوع
