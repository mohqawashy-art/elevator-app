# LiftCore — سياسة الخصوصية (L5)

**نموذج للعميل B2B — يُخصَّص باسم الشركة المشغّلة قبل النشر**

## 1. البيانات التي نجمعها

- بيانات العملاء والمباني (أسماء، عناوين، هواتف)
- بيانات العقود والفواتير والزيارات
- سجلات تدقيق (تسجيل دخول، حذف، تغيير إعدادات)
- بيانات الفنيين (جوال، PIN مُجزَّأ)

## 2. أين تُخزَّن البيانات

على بنية العميل (سيرفر مخصص أو GCP تحت حساب العميل ما لم يُتفق خلاف ذلك). لا نبيع البيانات لطرف ثالث.

## 3. من يصل للبيانات

| الدور | الوصول |
|------|--------|
| admin | كامل |
| manager | تشغيل بدون إعدادات حساسة |
| viewer | قراءة فقط |
| فني (بوابة /field) | زياراته وأعطاله فقط |

## 4. الأمان

- HTTPS إلزامي في الإنتاج
- كلمات مرور مُجزَّأة + سياسة قوة
- CSRF + rate limiting
- نسخ احتياطي مشفّر حسب إعداد السيرفر

## 5. الاحتفاظ والحذف

يحددها العميل كمالك البيانات. عند إنهاء العقد: تصدير DB + حذف من السيرفر حسب اتفاقية الخدمة.

## 6. اتصل بنا

يُستبدل ببيانات الشركة المشغّلة: البريد، الهاتف، العنوان.
