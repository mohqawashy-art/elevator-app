حزمة واتساب — عرض LiftCore
==========================

الطريقة الأفضل (رابط):
  https://liftcoreapp.com/deck

الطريقة البديلة (offline):
  1. اضغط مجلد whatsapp-pack كاملاً ZIP
  2. أرسل ZIP على واتساب
  3. العميل يفك الضغط ويفتح index.html في Chrome/Safari

مهم: لا ترسل index.html لوحده — لازم مجلد images معاه.
