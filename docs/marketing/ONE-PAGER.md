## ما هو LiftCore؟

نظام تشغيل لشركات صيانة وتركيب المصاعد في السعودية: عملاء، عقود، زيارات، أعطال، مخزون، فواتير ZATCA QR، وبوابة فني جوال.

## ما يشمله العقد النموذجي

- مستخدمون غير محدودين ضمن الخطة المتفق عليها (admin / manager / viewer)
- نشر مخصص على سيرفر العميل أو GCP مُدار
- نسخ احتياطي يومي + استعادة موثّقة
- تدريب تشغيل (جلسة واحدة)
- دعم تصحيح أخطاء خلال فترة الضمان المتفق عليها

## ما لا يشمله (ما لم يُذكر صراحة)

| البند | الملاحظة |
|-------|----------|
| SaaS متعدد المستأجرين | P3 — بيع B2B مخصص حالياً |
| ZATCA Phase 2 (XML/clearance) | QR Phase 1 على الطباعة فقط |
| WhatsApp Business API آلي | روابط wa.me يدوية |
| ترجمة تلقائية للمحتوى | حقول EN يدوية؛ لا `/api/translate` |
| Offline PWA للفني | حفظ محاضر بدون إنترنت + مزامنة تلقائية |
| فيديو تدريبي مخصص | اختياري كخدمة إضافية |

## المتطلبات من العميل

- شعار + بيانات شركة (سجل، ضريبة، بنك)
- مفتاح Google Maps (اختياري للخرائط)
- HTTPS + نطاق فرعي
- مسؤول نظام واحد على الأقل

2. استيراد بيانات (Excel) أو بداية من صفر
3. تسليم حساب admin + دليل مستخدم
