# LiftCore — دليل المستخدم (L1)

**للمشغّل اليومي (manager) والفني — نسخة نصية (صدّر PDF من المتصفح)**

## 1. تسجيل الدخول

- افتح رابط شركتك → أدخل اسم المستخدم وكلمة المرور
- غيّر كلمة المرور عند أول دخول إن طُلب منك

## 2. لوحة التحكم

- ملخص: عقود نشطة، زيارات اليوم، فواتير، أعطال مفتوحة
- اضغط البطاقات للانتقال للتفاصيل

## 3. العملاء

- **إضافة عميل:** زر «إضافة عميل» → الاسم، الجوال، المدينة، العنوان
- **الخريطة:** تبويب الخريطة يعرض مواقع العملاء (يتطلب عنواناً أو GPS)
- **كشف حساب:** من صفحة العميل أو التقارير المالية

## 4. العقود والمصاعد

- عقد صيانة مرتبط بعميل ومصعد/مصاعد
- تتبّع تاريخ الانتهاء — تنبيهات للعقود على وشك الانتهاء

## 5. الزيارات والأعطال

- **زيارة صيانة:** جدولة → تعيين فني → إكمال التقرير
- **عطل:** تسجيل → تعيين فني → طلب قطع إن لزم

## 6. الفواتير

- أنواع: فاتورة ضريبية، مبسطة، سند قبض
- **طباعة:** زر طباعة → QR ZATCA على الفواتير الضريبية
- **واتساب:** إرسال رابط/ملخص عند توفر رقم العميل

## 7. بوابة الفني (جوال)

- `/field/login` — جوال + PIN (يُعطيك إياه المشرف)
- عرض زيارات اليوم، تعبئة تقرير، إغلاق عطل

## 8. التقارير

- تقارير جاهزة: عملاء، عقود، فواتير، مخزون، فنيين
- **فروقات مالية:** `/reports/billing-discrepancies` (للمراجعة)

## 9. اللغة

- زر AR / EN في الهيدر يغيّر واجهة المكتب (لا يترجم الملاحظات التي كتبتها يدوياً)

## 10. الدعم

اتصل بمسؤول النظام في شركتك أو مزوّد LiftCore حسب عقدك.
