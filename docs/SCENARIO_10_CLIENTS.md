# سيناريو تجربة كامل — 10 عملاء (جما)

> **الهدف:** تجربة كل وحدات LiftCore على بيانات جاهزة واقعية.  
> **البيئة:** `jama.liftcoreapp.com` — عميل تجريبي.  
> **بعد التحميل:** القاعدة تحتوي 10 عملاء + عقود + زيارات + أعطال + مالية + مخزن + طلبات شراء + تقدير.

---

## التحضير (مرة واحدة)

### على سيرفر جما
```bash
cd ~/liftcore/jama-elevator-app
git pull origin main
bash deploy/reset_jama_demo.sh
```

### محلياً
```powershell
cd "D:\New folder\elevator-app"
python scripts/reset_jama_demo.py
python app.py
```

ثم **Ctrl+Shift+R** في المتصفح.

## مسار التجربة — كل الوحدات

### 1) لوحة التحكم
- [ ] افتح `/dashboard` — تحقق من KPIs (عملاء، عقود، زيارات اليوم، أعطال)
- [ ] راجع تنبيهات العقود المنتهية والمخزون المنخفض (#007 بكرة باب = 0)

### 2) العملاء والمصاعد
- [ ] `/clients` — خريطة + جدول — افتح **برج الياسمين**
- [ ] `/elevators` — فلتر حسب العميل — عدّل ملاحظة على EL-0124
- [ ] أضف عميلاً تجريبياً جديداً (العميل 11) للتأكد من التوليد التلقائي للأكواد

### 3) العقود
- [ ] `/contracts` — عقود تنتهي خلال 30 يوم (CN-00006 …)
- [ ] جدّد عقد **مجمع الروضة** (CN-00014 منتهي)
- [ ] اطبع/صدّر عقداً نشطاً

### 4) الفنيون
- [ ] `/technicians` — 7 فنيين بحالات مختلفة (متاح، مشغول، إجازة)
- [ ] افتح **أحمد الزهراني** — تبويب التوقيع الرقمي (PIN موجود)
- [ ] عيّن فنيين متعددين على زيارة (انظر الصيانة)

### 5) الصيانة الدورية
- [ ] `/maintenance-visits` — 9 زيارات **اليوم** بحالات متنوعة
- [ ] افتح زيارة **مكتملة** — محضر فحص جاهز (checklist)
- [ ] أنشئ زيارة دورية جديدة لـ **فندق الأندلس** — فنيين: أحمد + خالد
- [ ] **تخطيط الشهر** — وزّع زيارات على أحياء مكة
- [ ] من الفني: `/field` → زيارة → محضر → توقيع رقمي → حفظ وإنهاء

### 6) الأعطال
- [ ] `/faults` — 6 مفتوحة + 1 محلول
- [ ] افتح **FA-02041** (مستشفى السلام) — فريق فني (أحمد + سعد)
- [ ] `/faults/.../report` — تقرير عطل + توقيع إلكتروني
- [ ] أغلق عطلاً من الفني: حفظ وإغلاق العطل

### 7) قطع الغيار والمخزن
- [ ] `/parts-billing` — 5 سجلات تركيب
- [ ] `/inventory` — 10 أصناف، رصيد منخفض على #007
- [ ] `/stock-movements` — حركة وارد MV-001 + صادر MV-002
- [ ] أضف حركة صادر مرتبطة بعطل FA-02041

### 8) المالية

### 9) طلبات الشراء
