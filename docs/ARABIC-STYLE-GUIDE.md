# LiftCore — معيار العربية في الواجهة

**آخر تحديث:** أغسطس 2026  
**الغرض:** توحيد المصطلحات العربية ومراجعة الصفحات قبل demo أو تسليم عميل.

---

## 1) القاعدة العامة

| البند | المعيار |
|-------|---------|
| **اللغة الافتراضية** | عربي (RTL) — لا يظهر نص إنجليزي ثانٍ في نفس السطر |
| **الإنجليزية** | تظهر فقط عند تبديل اللغة (EN) عبر `LiftCoreI18n` |
| **المصدر** | القوالب عربي → `liftcore-translations.js` للإنجليزية |
| **CSS** | `static/liftcore-i18n-ui.css` — يخفي `.lc-en-only` في AR |

## 4) خطوات المراجعة لكل صفحة

1. افتح الصفحة بـ **AR** (الافتراضي).
2. سجّل أي كلمة **إنجليزية** ظاهرة (ما عدا: LiftCore، IBAN، CSID، أسماء ماركات مصاعد).
3. بدّل إلى **EN** — تحقق أن العربية اختفت.
4. راجع **RTL**: محاذاة الجداول، الأزرار، القوائم.
5. اطبع/صدّر PDF — تحقق من العناوين.

## 5) أدوات مساعدة

```bash
# استخراج نصوص عربية من القوالب
python tools/extract_i18n_strings.py

# اختبار ملف الترجمة
pytest tests/test_i18n_translations.py

# بحث عن إنجليزي في القوالب
rg '>[A-Z][a-zA-Z ]+<' templates --glob '*.html'
```
