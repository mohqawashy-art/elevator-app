# LiftCore — إعداد PIN بوابة الفني (K2)

## الغرض

الفنيون يدخلون من الجوال عبر `/field/login` برقم الجوال + PIN (4–6 أرقام)، بدون حساب مستخدم كامل في النظام.

## خطوات الإعداد (مدير النظام)

1. **إعدادات الشركة** → تبويب **بوابة الفني** (أو من صفحة **الفنيين**).
2. لكل فني نشط:
   - تأكد من **رقم الجوال** صحيح (صيغة سعودية: `05xxxxxxxx`).
   - اضغط **تعيين PIN** أو **تغيير PIN**.
   - أدخل PIN من 4–6 أرقام — يُخزَّن مُجزَّأ (hash) ولا يُعرض مرة أخرى.
3. أرسل للفني:
   - رابط البوابة: `https://YOUR-DOMAIN/field/login`
   - رقم جواله المسجّل
   - PIN (شفهياً أو عبر قناة آمنة — لا واتساب جماعي)

## اختبار سريع

```bash
# من السيرفر أو محلياً
curl -s -o /dev/null -w "%{http_code}" https://YOUR-DOMAIN/field/login
# يجب 200
```

من المتصفح (جوال أو DevTools → mobile):

1. افتح `/field/login`
2. أدخل جوال الفني + PIN
3. يجب الانتقال إلى `/field` مع قائمة زيارات/أعطال اليوم

## أمان

| البند | الوضع |
|--------|--------|
| Rate limit | مفعّل على `/field/login` |
| CSRF | معفى لمسارات `/field/*` (جلسة منفصلة) |
| RBAC مكتبي | الفني لا يرى لوحة الإدارة |
| PIN | hash فقط في قاعدة البيانات |

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| «رقم غير مسجّل» | أضف/صحّح الجوال في صفحة الفنيين |
| «PIN غير صحيح» | أعد تعيين PIN من الإعدادات |
| صفحة بيضاء على iOS | تأكد من HTTPS + تحديث المتصفح |
| لا تظهر زيارات | تحقق من تعيين الفني على الزيارة/العطل لنفس اليوم |
